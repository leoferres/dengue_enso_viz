# Colombia: dengue & ENSO

Frozen inputs. Needs Linux, QGIS 3.44 with Python, NumPy, Matplotlib, and FFmpeg. Fonts included, just in case.

```sh
/usr/bin/python3 -I render.py
```

Writes the 30 fps, 76-second MP4 to `output/`. Original: `reference.mp4`.

[Sources and limits](SOURCES.md). [Tested versions](environment.json).

Checked for consistency. Comments/pull requests welcome.
